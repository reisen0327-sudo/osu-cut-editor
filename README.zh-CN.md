# osu! Cut Editor

简体中文 · [English](README.md)

一款 Windows 桌面工具，可同时从 osu! 谱面和音频中删除指定时间区间，再导出为独立副本。

**当前版本：1.0.0 · Windows x64 · 便携式程序**

应用界面目前使用简体中文，中英文文档介绍相同的功能。

## 下载

从 [Release v1.0.0](https://github.com/reisen0327-sudo/osu-cut-editor/releases/tag/v1.0.0) 下载 `osu-cut-editor-1.0.0.exe`，直接运行即可，无需安装程序或 Node.js。

仓库及 Release 目前为私有，下载需要拥有仓库访问权限。

## 快速开始

1. 导入一个或多个 `.osu` 文件、谱面文件夹，或 `.osz` 压缩包。
2. 从列表中选择难度，播放或跳转到需要编辑的位置。
3. 在 **Cut 区间** 中设置起止时间。输入毫秒或游戏时间戳，另一栏会自动换算。例如，`00:02.500`–`00:05.500` 对应 `2500`–`5500 ms`。
4. 点击 **执行 Cut** 删除该区间，再预览结果。可使用 **撤销**、**重做** 或 **恢复原始**。
5. 点击 **导出独立副本** 保存为文件夹，或点击 **导出 .osz** 保存为压缩包。

`sample/` 中提供了小型合成 standard、4K mania 谱面及生成的音频，可用于体验上述流程。

## 功能

### 可视化与导航

- **osu!mania**：参考游戏内编辑器设计轨道、银白/粉色长条（LN）、细头尾、节拍线和时间标尺；根据 `CircleSize` 显示 1–18 列。
- 密集 LN 的头尾厚度随相邻时间间距调整；先绘制长条主体，再绘制头尾，避免绘制顺序造成遮挡。
- 使用 **0.50×–8.00×** 滚动速度滑动条，步长为 **0.01×**。仅改变画面间距和滚动速度，不改变音频速度或谱面时间。
- **osu!standard**：提供圆圈、滑条、转盘及背景的参考画面。
- 时间轴显示小节、节拍和细分刻度；支持拖动选区、滚轮按节拍分度跳转，以及将当前拍点锚定为剪切端点。
- 时间戳与毫秒双向换算。`00:49.809` 和复制形式 `00:49:809` 均对应 `49809 ms`，并保留小数毫秒精度。
- 支持音频播放、暂停、跳转和实时播放头。

### 剪切规则

**Cut 会删除选定区间，而不是只保留该区间。**

- 使用 **[开始, 结束)** 区间：包含起点，不包含终点。
- 区间内的单点音符会被删除；与区间相交的滑条、转盘或长按物件整体删除；恰好在起点结束的长物件保留。
- 后续物件、TimingPoint 和休息区间按剪切时长前移；必要时，在切口恢复仍然有效的 BPM、滑条速度（SV）、音量和采样音效设置。
- 预览时间和编辑器书签同步调整。区间内的书签删除，跨越切口的休息区间保留剩余时长。
- 音频按采样点边界剪切，并编码为 **16-bit PCM WAV**；单次实际剪切时长与请求区间的误差小于一个采样周期。
- `Title` 和 `TitleUnicode` 只追加一次 ` (Cut. Ver)`。
- 谱面和音频均处理成功后才更新编辑状态。支持最近 10 步撤销/重做，并可恢复本次加载的原始内容。
- 拒绝无效时间戳、缺少音频、删除整段音频、超出音频长度，以及不足一个采样点的剪切。

### 导入与导出保护

- 每次文件夹导出均创建唯一目录，保留源文件和以前的导出结果。
- 从 `.osu` 导入时，副本创建在源谱面目录内；从 `.osz` 导入时，副本创建在原压缩包旁。
- 导出压缩包时拒绝覆盖已有文件。
- 复制背景、自定义音效及子目录资源，排除原谱面、原主音频及已有 `.osz` 文件；新音频名称会避开资源重名。
- 导出结果移除视频、独立 `.osb` 文件、内嵌故事板事件和故事板变量。
- 新谱面使用 `BeatmapID:0`、`BeatmapSetID:-1`；缺少源背景时会提示。
- 压缩包导入支持子目录谱面，并拒绝越界路径、Windows 非法名称、大小写重名、文件与目录冲突和损坏数据。
- 导入限制：压缩包与单个解压文件各不超过 **512 MiB**，解压总量不超过 **1 GiB**，最多 **10000** 个条目。
- 导入失败会清理本次解压目录并保留当前编辑；正常退出时清理本次会话创建的解压目录。

## 开发与构建

已在 Windows 上使用 Node.js **24.18.0**、pnpm **11.22.0**、Electron **44.7.2** 和 electron-builder **26.15.3** 验证。项目通过 `packageManager` 固定 pnpm 版本，并提供 `pnpm-lock.yaml`。

```powershell
pnpm install --frozen-lockfile
pnpm start

# 构建 Windows x64 便携式程序
pnpm dist
# 产物：dist/osu-cut-editor-1.0.0.exe
```

首次安装或构建可能需要下载 Electron 和打包工具。可按网络环境配置 `ELECTRON_MIRROR` 和 `ELECTRON_BUILDER_BINARIES_MIRROR` 下载镜像。

项目已提供可直接使用的图标。使用 `scripts/make-icon.py` 重新生成图标时，需要 Python 和 Pillow。

| `main.js` | Electron 窗口、文件对话框及导入/导出 IPC |

## 已知限制

- 任意时间剪切可能造成听感上的突变。补回的红线以切口作为节拍起点；本工具不提供淡入淡出或音乐过渡编辑。
- 解压、资源复制和压缩仍同步执行，大文件操作可能暂时阻塞界面；长音频及撤销历史可能占用较多内存，尚未完成超大文件压力测试。
- 强制结束程序或系统异常退出可能残留解压目录。自动清理仅涉及当前会话创建的目录。
- 已测试 standard 和 mania 流程；taiko、catch 以及在 osu! 客户端中的实际导入和游玩尚未专项验证。
- standard 画布仅用于参考，并非对游戏渲染效果的完整复现。
